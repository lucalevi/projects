# projects

Hands-on code from a self-directed, university-level Computer Science course. The goal is to understand AI/ML from a rigorous CS perspective (algorithms, systems, theory of computation, mathematics) rather than as a user of libraries.

The course is organised in phases; each phase ends with a small practical project, and every project lives in its own folder here.

## Projects

| Phase | Folder | Description | Status |
|-------|--------|-------------|--------|
| 0 - How a computer thinks | [Module 0 - Logical/binary calculator](<Module%200%20-%20Logical:binary%20calculator/>) | Base conversion, two's complement arithmetic, and a boolean-expression evaluator with truth tables | In progress |

Each project folder has its own `README.md` with details and instructions for running the code.

## Conventions

- Python 3, standard library only (no dependencies to install).
- Every script contains its own tests in an `if __name__ == "__main__":` block using plain `assert`, so `python <file>.py` runs them.
- Code comments, error messages and test output are written in Italian; documentation is in English.
